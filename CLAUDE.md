# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

ScarcePay is a self-hosted, multi-chain crypto invoicing system (BTCPay Server clone). Merchants accept payments in any crypto, and NEAR Intents (1Click API) handles cross-chain swaps for settlement.

## Commands

```bash
# Install dependencies
pnpm install

# Start both apps in parallel (web on 3000, api on 3001)
pnpm dev

# Build all packages
pnpm build

# Lint all packages
pnpm lint

# Run web tests
pnpm --filter @scarce-pay/web test

# Production deployment (1-click setup)
export SCARCEPAY_HOST="pay.example.com"
. ./scarcepay-setup.sh -i

# Local Docker (development)
docker compose up
```

### App-specific commands

```bash
# API (apps/api)
pnpm --filter @scarce-pay/api dev      # tsx watch
pnpm --filter @scarce-pay/api build    # tsc

# Web (apps/web)
pnpm --filter @scarce-pay/web dev      # vite on port 3000
pnpm --filter @scarce-pay/web build    # vite build
pnpm --filter @scarce-pay/web test     # vitest
pnpm --filter @scarce-pay/web check    # biome check
```

## Architecture

```
scarce-pay/
├── apps/
│   ├── api/     # Hono backend (port 3001)
│   └── web/     # TanStack Start frontend (port 3000)
├── packages/
│   ├── eslint-config/
│   ├── tailwind-config/
│   └── typescript-config/
├── scarcepay-setup.sh  # 1-click deployment script
├── docker-compose.yml
└── Caddyfile
```

### API (apps/api)
- **Framework**: Hono with `@hono/node-server`
- **Port**: 3001
- **Entry**: `src/index.ts`
- **Build output**: `dist/`
- **Health check**: `GET /api/health`

### Web (apps/web)
- **Framework**: TanStack Start (React 19 + TanStack Router)
- **Port**: 3000
- **Styling**: Tailwind CSS v4 via `@tailwindcss/vite` plugin
- **Linting**: Biome (tabs, double quotes)
- **Testing**: Vitest
- **Build output**: `.output/` (Nitro)
- **Routing**: File-based in `src/routes/`

### Infrastructure
- **Caddy**: Routes `/api/*` → api:3001, everything else → web:3000
- **PostgreSQL**: postgres:17-alpine, database `scarcepay`
- **Docker network**: `scarcepay` bridge

### Environment Variables

**Local development** — create `apps/api/.env`:
```bash
cp apps/api/.env.example apps/api/.env
```
Contains: `DATABASE_URL=postgresql://postgres:postgres@localhost:5432/scarcepay`

**Docker/Production** — set via docker-compose or setup script:
- `POSTGRES_PASSWORD` - Database password (auto-generated by setup script)
- `NEAR_INTENTS_API_KEY` - 1Click API key for payment processing
- `SCARCEPAY_HOST` - Domain for the instance (e.g., pay.example.com)

Note: `DATABASE_URL` is constructed automatically in docker-compose.yml from the postgres credentials.

## Code Style

- **TypeScript**: Use `type` over `interface`
- **File organization**: Newspaper pattern—main export first, helpers next, types at bottom
- **Imports**: Use `clsx/lite` not `clsx`
- **Web formatting**: Biome handles formatting (tabs, double quotes)
